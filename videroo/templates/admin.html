Accès au navigateur — deux façons

Mode actuel : {{ 'Chrome existant' if mode_navigateur == 'chrome_existant' else 'Profil dédié' }} (se change dans Réglages → Comptes, plus bas).

1. Profil dédié par défaut

Une fenêtre séparée de ton Chrome, avec ses propres sessions. Tu t'y connectes une fois par service.

Limite connue : Google refuse souvent la connexion depuis une fenêtre pilotée et renvoie une erreur 400. Si ton compte ChatGPT passe par « Se connecter avec Google », utilise la méthode 2.

2. Chrome existant contourne le blocage

Videroo se branche sur ton Chrome, là où tu es déjà connecté : aucune connexion à refaire, donc aucun blocage Google.

  1. Ferme complètement Chrome (toutes les fenêtres).
  2. Lance cette commande dans un terminal :
  1. Passe le mode sur « Chrome existant » et enregistre.
  2. Clique sur « Tester le branchement », puis « Vérifier » sur chaque compte.
Dans ce mode, Videroo agit dans ton Chrome personnel : il peut donc atteindre les sites où tu es connecté. Il ne pilote que ChatGPT et Grok, et ne ferme jamais ton navigateur.
